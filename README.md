# UniTest Prep — Entry Test MCQ Practice

**Live web demo:** https://zardariprivacy-cell.github.io/Privacy/
**Android app (4,480 MCQs, free):** https://drive.google.com/uc?id=1kF0AWDSx5WfLgStzgMFshvBc70C6l7I1&export=download

A free practice app for students preparing for university entry tests in Pakistan (**MUET, NED, UET, ECAT** and more) — Pre-Engineering pattern. The Android app has 4,480 MCQs (50 per topic: Mathematics, Physics, Chemistry, English); this web version is a small free demo.

## What is inside

- **4 subjects:** Mathematics, Physics, Chemistry, English
- **40 beginner-level MCQs** (10 per subject), each with a simple explanation
- **Practice Mode:** answer a question and see instantly if you are right or wrong, with the reason
- **Mock Test Mode:** 20 mixed questions, 20-minute timer, full review at the end
- Best score per subject on the home screen

The real MUET test has 100 MCQs and **no negative marking** — always attempt every question.

## How to use

Open `index.html` in any browser, or use the GitHub Pages link of this repository if enabled. No login, no internet needed after the page loads.
